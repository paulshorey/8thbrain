# Knowledge Documents

All research output should be stored by topic:

```text
docs/{topic-title}/
  intro.md
  perspectives.md
  research-report-YYYY-MM-DD.md
  {sub-topic}.md
```

Guidelines:

- `intro.md` = broad synthesis and navigation page for the topic
- `perspectives.md` = supporting/critical/mixed views and unresolved disagreements
- `research-report-YYYY-MM-DD.md` = dated snapshot of findings and source updates
- subtopic files = deeper treatment of specific complex areas
- keep citations close to claims
- prefer updating existing topic folders over creating duplicates
