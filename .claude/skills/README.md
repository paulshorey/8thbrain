# Orchestrator Skills

**For agents:** These skills run in the main context after subagent research. Read each `SKILL.md` and execute its phases in order. Do not run skills in parallel.

| Skill | When to Run | Phases |
|-------|-------------|--------|
| dialectical-analysis | Topic has meaningful disagreement, competing approaches, multiple perspectives | 1–5 |
| research-documentation | Always, after combine (and optionally dialectical-analysis) | 1–9 |

**Invocation:** Read the SKILL.md file. Execute phases sequentially. Complete each phase's gate before proceeding. Do not skip phases.
