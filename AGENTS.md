# Agent Rules for Knowledge Base Project

This is a **knowledge base** repository, not a traditional codebase. The agent's role is to:

- Expand the knowledge base through rigorous research (Deep Research + Perplexity MCP when needed)
- Document findings in `./docs/{topic}/` following the Document Research skill
- Keep the file system organized, merge with existing content, and cite sources

Rely on the skills in `.claude/skills/` and the instructions in `CLAUDE.md`.
